JavaScript
Evolucija

Jezik napisan za 10 dana, koji nije obećavao ništa posebno, koji je godinama bio smatran "ne pravim programiranjem" — danas jedini jezik koji radi u browseru, na serveru, u bazi, u mobilnim aplikacijama i u AI toolingу.

// kako je sve počelo

10 dana — Brendan Eich, Netscape, 1995.

⚡
Istorijska činjenica: Brendan Eich je napisao prvi prototip JavaScript-a za 10 dana u maju 1995. Netscape je hteo "Javu za web" — nešto jednostavno, za neprogramere. Eich je dobio zadatak da napravi jezik koji izgleda kao Java ali ima Scheme semantiku ispod. Rezultat: jezik koji nije bio ni Scheme ni Java, ali je radio i pokrenuo revoluciju.
Originalna imena

Mocha → LiveScript → JavaScript

Eich ga je nazvao Mocha. Netscape marketing ga preimenuje u LiveScript. Zatim — u dogovoru sa Sun Microsystems — postaje JavaScript. Čisto marketing: Java je bila popularna, ime je trebalo da privuče pažnju. JavaScript i Java nemaju nikakve veze osim naziva.

Microsoft odgovara

JScript — 1996

Microsoft kopira JavaScript za IE — ali ne smije koristiti ime zbog licenci. Zove ga JScript. Neznatno drugačija implementacija. Ovo je početak browser ratova — isti kod, različito ponašanje u Netscape-u i IE-u. Web developeri pišu if (document.all) da detektuju IE.

// hronologija — 30 godina u 10 tačaka
1995
★ Rođenje
JavaScript 1.0 — Netscape Navigator 2.0
Dinamički tipovi, prototypalna nasleđivanja, first-class funkcije. Može menjati DOM, validirati forme, animirati elemente. Kritika je bila žestoka — "to nije pravi jezik", "toy language", "za neprogramere". Istovremeno: svako ko je htio da stranica "radi nešto" morao ga je koristiti.
10 dana razvoja Dinamički tipovi DOM manipulacija Kritikovan odmah
1997
Standard
ECMAScript 1 — ECMA-262
Netscape predaje JavaScript ECMA standardizacionom tijelu. Nastaje ECMAScript — zvanično ime standarda. JavaScript je implementacija ECMAScript standarda. (SpiderMonkey u Firefoxu, V8 u Chromeu, JavaScriptCore u Safáriju — sve su implementacije istog standarda.)
2005
★ Ajax revolucija
Ajax — Jesse James Garrett imenuje tehniku
XMLHttpRequest postoji od 1999. (Microsoft u IE). Ali tek 2005. Jesse James Garrett piše članak i imenuje tehiku: Ajax. Gmail (2004.) i Google Maps (2005.) dokazuju — web može biti aplikacija, ne samo dokument. JavaScript više nije "toy" — gradi Gmail.
XMLHttpRequest Async bez reload-a Gmail na JS-u
2006
★ jQuery
jQuery — "Write Less, Do More"
John Resig objavljuje jQuery. Ubija cross-browser probleme. $(selector).action() radi isto u IE i Firefoxu. Polyfill za desetak godina browser haosa. Na vrhuncu popularnosti — 78% svih web sajtova koristilo je jQuery. I danas živi na milionima sajtova.
Cross-browser fix 78% web sajtova I danas živ
2009
★ Node.js — JS izlazi iz browsera
Ryan Dahl — JavaScript na serveru
Prekretnica. Ryan Dahl uzima Chrome-ov V8 engine i stavlja ga van browsera. JavaScript može čitati fajlove, otvarati TCP konekcije, biti HTTP server.

Isti jezik — frontend i backend. Full-stack JavaScript postaje stvarnost. npm nastaje 2010. — danas najveći package registry na svetu, 2+ miliona paketa.

2015
★ ES6 / ES2015 — moderni JS
ECMAScript 2015 — jezik se transformiše
Najveći skok od 1995. let, const, arrow functions, classes, modules (import/export), template literals, destructuring, spread operator, Promise, Symbol, Map, Set, generators...

JS više ne izgleda kao krpež — izgleda kao ozbiljan jezik. Babel kompajler omogućava korištenje ES6 na starim browserima odmah.
ES5 vs ES6
// ES5 (staro)
var add = function(a, b) { return a + b; };
var name = user.name || 'Anonymous';

// ES6 (novo)
const add = (a, b) => a + b;
const { name = 'Anonymous' } = user;
const msg = `Hello, ${name}!`;
Arrow functions import/export Promise Destructuring Classes
2017
async/await
ES2017 — asinhroni kod postaje čitljiv
Callback hell → Promise → async/await. Asinhroni kod koji izgleda kao sinhroni. Jedna od najvažnijih ergonomskih poboljšanja jezika.
Callback hell → async/await
// Callback hell (staro)
fetch(url, function(err, data) {
  parseJSON(data, function(err, obj) {
    saveDB(obj, function(err) { // ... })
  })
})

// async/await (novo)
const data = await fetch(url);
const obj = await parseJSON(data);
await saveDB(obj);
2012
★ TypeScript
Microsoft TypeScript — JS sa tipovima
Anders Hejlsberg (C# kreator) projektuje TypeScript. JavaScript sa statičkim tipovima koji se kompajlira u čisti JS. Angular 2 (2016) napisan u TypeScript-u — industrija prihvata. Danas: svaki ozbiljan projekat, svaki framework, svaki novi starter. TypeScript nije zamena za JS — to je JS sa super moćima.
Statički tipovi Kompajlira u JS Anders Hejlsberg 2022+ de facto standard
// javascript i baze podataka

JS ulazi u bazu podataka

Node.js je JS odveo na server. Ali JS je otišao još dalje — direktno u bazu podataka.

MongoDB — Document DB

JavaScript u upitima

MongoDB koristi JavaScript sintaksu za upite i agregacije. JSON dokumenti nativno — nema ORM-a, nema mapiranja. Isti jezik koji pišeš u React-u, pišeš i u MongoDB shell-u.

MongoDB — JS upitiMongoDB
// Isti JS sintaksa u bazi
db.users.find({
  age: { $gte: 18 },
  city: 'Beograd'
}).sort({ name: 1 });

// Agregacija sa JS pipeline-om
db.orders.aggregate([
  { $group: { _id: '$city',
    total: { $sum: '$amount' } } },
  { $sort: { total: -1 } }
]);
JSON dokumenti JS upiti Bez ORM-a
Ostale JS baze

CouchDB, Deno KV, PouchDB

CouchDB — JavaScript za MapReduce views. PouchDB — IndexedDB wrapper, radi u browseru, sinhronizuje sa CouchDB serverom. Deno KV — key-value baza ugrađena u Deno runtime. Cloudflare D1 — SQLite na edge-u, queryuješ iz JS Worker-a.

CouchDB PouchDB (browser) Deno KV Cloudflare D1
🔄
JS stack 2024: React (browser) → Next.js (server) → Node.js/Express (API) → MongoDB (baza) → Redis (cache). Jedan jezik, cijeli stack. Isti developer može pisati UI komponentu i database query. To je bio san 2009. kada je Node nastao. Danas je realnost.
// šta je zapravo "vanilla js"

Vanilla JS — zašto baš "vanilla"?

"Vanilla" dolazi iz sladolednog žargona — vanilla je podrazumevani ukus, bez dodataka. "Vanilla JS" znači čisti JavaScript bez ijednog frameworka ili biblioteke. Samo ono što browser ima ugrađeno.

⚠️
Pažnja — postoji i VanillaJS.com: Sajt koji se šali na račun JS frameworka. Tvrdi da je "VanillaJS" najbrži framework — jer je čisti browser API, nula KB download. Nije pravi framework. Satirična šala koja zbunjuje početnike. Vanilla JS = čisti JS, bez frameworka. Ne mešati.
Vanilla JS primjeri u produkcionom kodu

Zašto vanilla za embeds
Nula zavisnosti

FB Pixel ne zna koji framework koristiš. Mora raditi na svakom sajtu — WordPress, React, plain HTML.

Veličina

Embed skripta mora biti mala. React 18 = 45KB. Vanilla fetch + DOM API = 0KB overhead.

Trajnost

Framework version se mijenja. document.getElementById radi od 1998. i radi u 2025.

Performance

Google Analytics se učitava asinhrono, ne blokira render. Vanilla async je native.

// npm — najveći ekosistem paketa na svetu

npm — 2+ miliona paketa

Node Package Manager (2010) je danas najveći softverski registar na svetu. Svaka ozbiljna JS biblioteka ima npm paket. I mnoge koje nisu ozbiljne — is-odd, left-pad (čija 11-linijska brisanje je srušila pola interneta 2016.).

📦
left-pad incident — 2016: Developer Azer Koçulu obrisao je left-pad sa npm-a (11 linija koda). React, Babel, stotine projekata prestali da se kompajliraju. npm je morao prisilno da vrati paket bez dozvole autora. Otvorilo je pitanje: da li je OK da cijeli internet zavisi od 11 linija koda? Odgovor je bio: ne. npm je uveo politiku nepovratnog brisanja popularnih paketa.
