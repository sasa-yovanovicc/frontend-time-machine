► STA JE WORLD WIDE WEB?

Veb nije softver koji se instalira. Veb je mreza dokumenata koji se medjusobno linkuju — kliknes i odjes na drugi dokument. Tim Berners-Li ga je izmislio 1991. u CERN-u za razmenu naucnih radova.

HTML = HyperText Markup Language
HTTP = HyperText Transfer Protocol
URL = Uniform Resource Locator
WWW = World Wide Web
► YAHOO PROBLEM (1995.)

Yahoo nije program koji se instalira. Yahoo je veb sajt — direktorijum linkova organizovan po temama, dostupan kroz Netscape Navigator brauzer.

Danasnji ekvivalent bi bio da neko pita: "kako da instaliram Google?" — jer pojam sajta koji postoji na udaljenom racunaru, a ti ga samo gledas kroz brauzer, bio je potpuno nov koncept.

★ DREAMWEAVER: PRAVA REVOLUCIJA! ★
