# Frontend Vremenska Masina

Interaktivna prezentacija o evoluciji frontend razvoja kroz 30 godina —
od terminala i zelenih fosfor monitora do AI koji generiše vizuelne 
interfejse direktno u razgovoru.

Prezentacija je pripremljena i održana u Srednjoj školi "Nikola Tesla",
Budimpešta, 21. maja 2026.

## Tehnički detalji

- Čisti HTML/CSS/JavaScript — bez build procesa, bez npm
- Svaka era prikazana tehnologijom tog doba:
  - era0: inline stilovi (pre-CSS autentičnost)
  - era1: HTML 3.2 bez CSS-a
  - era2: CSS float layout, XHTML
  - era3: Bootstrap 3.4.1 via CDN
  - era4: CSS Grid, custom properties, React 18 via CDN
  - era5–: moderni CSS, Fira Code, Syne Mono
- CSS fajlovi u css/ folderu (era2.css, era3.less, era4.scss itd.)
- Demo fajlovi u demo/ folderu
