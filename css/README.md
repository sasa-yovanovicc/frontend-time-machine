## Napomene

- `era0-rodjenje.html` i `era1-1994.html` nemaju eksternih stilova — autentičnost ere.
- `.less` i `.scss` fajlovi su edukativni: pokazuju kako je izgledao source kod u tom periodu.
- Browseri učitavaju `.css` fajlove; `.less`/`.scss` sadrže originalnu CSS logiku + preprocesorkse varijable na vrhu.
