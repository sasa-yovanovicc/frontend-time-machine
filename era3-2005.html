CSS Cascade Layers & 3D DevTools

Dva velika pomaka u razumevanju i debagiranju CSS-a.

CSS Cascade Layers @layer

Pre @layer, specifičnost CSS-a bila je noćna mora — jedan !important u plugin-u mogao je da pokvari ceo dizajn. Cascade Layers daju eksplicitnu kontrolu prioriteta. 

@layer base, theme, utilities;

@layer base {
  a { color: blue; }
}
@layer theme {
  a { color: rebeccapurple; }
}
@layer utilities {
  .urgent { color: red; }
}

 Redosled deklaracije layera određuje prioritet — utilities uvek pobeđuje bez obzira na specifičnost.

Chrome DevTools — Layers Panel kompozicija

Chrome Layers panel prikazuje koje elemente GPU kompozituje kao posebne slojeve. Svaki will-change, transform ili position:fixed kreira novi compositing layer — ovo objasnjava zasto animacije nekad "trepere" ili zasto scroll performans pati.

 Sta vidis: 3D prikaz svakog compositing layera, razlog zbog kog je napravljen, velicinu memorije, i paint count.

Microsoft Edge DevTools — 3D View

Sta je 3D View?

Edge DevTools 3D View prikazuje tvoj DOM kao trodimenzionalni dijagram. Svaki HTML element je "ploca" u prostoru. Dubina odgovara dubini u DOM stablu — sto je element dublje ugnjezden, to je dalje od posmatraca.

Posebno koristan za z-index probleme — vidis tacno koji element je "iznad" kog i zasto se overlay ne prikazuje kako ocekujes.

Kako otvoriti
  1. Otvori Edge browser
  2. Pritisni F12 ili Ctrl+Shift+I
  3. Klikni na "…" (vise alata)
  4. Izaberi "3D View"
  5. Prebaci izmedju DOM / Z-index / Composited Layers
Tri rezima prikaza
Z-index
Boji elemente po z-index vrednosti. Odmah vidis koji element "prekriva" koji. Trazis zasto modal ne moze da se klikne? Ovde.
DOM
Svaki DOM element kao ploca u prostoru. Dubina = ugnjezdenost. Vizualizuje koliko je tvoj DOM dubok i gde je "tezak".
Composited Layers
Koji elementi su promovisani u GPU layer? will-change, transform, position:fixed — sve sto GPU renderuje posebno.

Chrome DevTools — Layers Panel

Sta je Layers Panel?

Chrome Layers Panel prikazuje koje elemente GPU renderuje kao posebne compositing layere. Svaki layer je zasebna tekstura u grafickoj memoriji.

Animacije koje rade iskljucivo na GPU-u (transform, opacity) su 60fps uvek — ne blokiraju main thread. Layers panel pokazuje da li tvoja animacija zaista koristi GPU.

Previse layera = problem. Svaki layer trosi GPU memoriju. will-change: transform na 500 elemenata = crash na mobilnom.
Kako otvoriti
  1. Otvori Chrome DevTools (F12)
  2. Klikni "…" (More tools)
  3. Izaberi "Layers"
  4. Klikni na layer da vidis detalje

Razlika u pristupu — jQuery vs React
/* jQuery pristup — imperativan, 2010. */
$('#like-btn').click(function() {
  var count = parseInt($('#count').text());
  $('#count').text(count + 1);
  $('#like-btn').addClass('liked');
  $('#like-btn').find('i').removeClass('fa-heart-o').addClass('fa-heart');
});

/* React pristup — deklarativan, 2013. */
function LikeButton() {
  const [liked, setLiked] = useState(false);
  return <button onClick={() => setLiked(true)}>
    {liked ? '❤️ Svidja mi se' : '🤍 Like'}
  </button>;
}
