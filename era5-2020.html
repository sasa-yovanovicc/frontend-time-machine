Server Components

1994. sve je bilo na serveru. 2013. sve smo premjestili na klijenta. 2023. shvatamo da smo otišli predaleko.

ProductList.tsx Server Component 
// Server Component — nema "use client"
// Nula JS-a u brauzeru za ovu komponentu

async function ProductList() {
  // Direktno u bazu — nema fetch()
  const products = await db.query(
    'SELECT * FROM products'
  );

  return (
    <ul>
      {products.map(p => (
        <li>
          {p.name}
          // Client component za dugme
          <AddToCart id={p.id} />
        </li>
      ))}
    </ul>
  );
}

✓ Sta dobijamo

Lista 1000 proizvoda: nula JS u brauzeru. Dugme za svaki: minimalan JS samo za klik. Bundle 60% manji.
