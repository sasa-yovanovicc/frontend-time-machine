// problem — web za jedan ekran

Pre responsive-a — fiksni layout

Web je 1993-2007. bio dizajniran za jedan ekran. Najpre 640px (VGA), zatim 800px, zatim 1024px. Dizajneri su pisali width: 960px; margin: 0 auto; i smatrali posao završenim.

Problem 2007.

iPhone — ekran od 320px

Apple objavljuje iPhone. Ekran 320×480px. Svi web sajtovi dizajnirani za 960px+ izgledaju miniaturno. Safari na iPhoneu automatski zumira stranicu da stane. Ovo nije rešenje — to je zaobilaznica.

960px sajt na 320px ekranu Automatski zoom = loše UX
Rešenje 2010.

Ethan Marcotte — "Responsive Web Design"

Maj 2010, A List Apart članak. Termin "responsive web design" kuje Ethan Marcotte. Tri ingredijenta: fluid grids, flexible images, media queries. Isto URL, isti HTML, drugačiji CSS za svaki ekran.

Fluid grid Flexible images Media queries
// media queries — sintaksa

Media Queries — CSS 2 (1998) → CSS 3 (2012)

Media queries postoje od CSS 2 (1998) — ali samo za @media print i @media screen. CSS3 Media Queries (W3C Recommendation 2012) dodaju min-width, max-width, orientation, resolution i ostalo što danas koristimo.

Media Queries — evolucija sintakseCSS
/* CSS 2 (1998) — samo tip medija */
@media print { body { font-size: 12pt; } }
@media screen { body { font-size: 16px; } }

/* CSS 3 (2012) — min/max width — responsive revolucija */
@media (max-width: 768px) {
  .sidebar { display: none; }
}

@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
}

/* Orientation */
@media (orientation: landscape) { ... }

/* Retina / HiDPI (2012) */
@media (-webkit-min-device-pixel-ratio: 2),
       (min-resolution: 192dpi) {
  /* @2x slike */
}

/* Moderni CSS (2022+) — prefers */
@media (prefers-color-scheme: dark) { ... }
@media (prefers-reduced-motion: reduce) { ... }
@media (prefers-contrast: high) { ... }

Breakpointi kroz ere

Odakle dolaze Bootstrap breakpointi? 768px = iPad portret (2010). 992px = iPad landcape + mali desktop. 1200px = standard desktop. Bootstrap 3 je kodifikovao ove vrednosti i cela industrija ih je prihvatila. Nisu izmišljeni — nastali su iz popularnih uređaja tog vremena.

Mobile First vs Desktop First

Desktop First — stari pristup

max-width — "skrni kad je malo"

Dizajniraš za desktop (1280px+), zatim dodaješ max-width media queries da "pokvariš" layout za mobilni. Mobilni uvek dobija "ostatke" od desktop dizajna.

/* Desktop first */
.grid { display: grid; grid-template-columns: repeat(3,1fr); }

@media (max-width: 768px) {
  .grid { grid-template-columns: 1fr; }
}
Mobile First — Luke Wroblewski 2009

min-width — "širi kad je veće"

Dizajniraš za mobilni (320px) — samo ono što je nužno. Zatim dodaješ min-width queries da proširuješ layout. Desktop je unapređenje mobilnog, ne obrnuto.

/* Mobile first */
.grid { display: grid; grid-template-columns: 1fr; }

@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(3,1fr); }
}
// fluid jedinice — kraj fiksnih piksela

%, vw, vh, rem, em, clamp()

Relativne jedinice
/* % — relativno na roditelja */
width: 50%;

/* vw/vh — relativno na viewport */
width: 100vw; /* puna širina */
height: 100vh; /* puna visina */

/* rem — relativno na root font-size */
font-size: 1.5rem; /* 24px ako je root 16px */

/* em — relativno na roditelja */
padding: 1em; /* = trenutni font-size */
clamp() — fluid bez media querijaCSS 2020+
/* clamp(min, ideal, max) */
font-size: clamp(16px, 4vw, 32px);
/* 16px na mobilnom */
/* raste sa ekranom */
/* max 32px na desktopu */

width: clamp(280px, 90%, 1200px);

/* Nema media query potrebe! */
/* Fluid je podrazumevano. */

// hronologija
1998

CSS2 @media — osnova

Media types: screen, print, handheld. Handheld nikad nije zaživio. Ali osnova za sve što dolazi.

2007

iPhone — problem postaje realan

Mobilni web eksplodira. Stari sajtovi izgledaju loše. Industrija traži rešenje.

2009

Mobile First — Luke Wroblewski

Knjiga "Mobile First" mijenja filozofiju dizajna. min-width umesto max-width. → Opširnije u Teme

2010

Responsive Web Design — Marcotte

Termin kuje Ethan Marcotte u A List Apart. Fluid grids + flexible images + media queries = responsive.

2013

Bootstrap 3 — responsive by default

Bootstrap 3 je prvi Bootstrap koji je Mobile First. col-xs-12, col-md-6 — responsive grid za mase. → Era3

2015

Google Mobilegeddon

Google počinje kažnjavati non-responsive sajtove u rangiranju. Responsive postaje obaveza, ne izbor.

2017

CSS Grid — pravi responsive layout

grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)) — responsive bez media querija. → Era4

2023

Container Queries — budućnost

Komponenta reaguje na svog roditelja, ne na viewport. Pravi komponentni responsive design.

🎯
Danas: responsive nije feature — to je default. Svaki framework, svaki starter template, svaki novi projekat je responsive od prvog dana. Pitanje više nije "da li je responsive" nego "koliko dobro se prilagođava" — od 280px smartwatch-a do 7680px 8K ekrana. → Evolucija monitora
