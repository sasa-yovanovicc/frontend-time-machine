Sve je Komponenta

Kraj jQuery imperativnog pristupa. Deklarativni UI — opisuješ kako treba izgledati, framework se brine o tome kako to postići.

⚛

React — "Just the View"

Facebook 2013. Nije framework — biblioteka. Samo UI. Virtual DOM. JSX. One-way data flow. Ti biraš sve ostalo.

💚

Vue.js — Progressive Framework

Evan You 2014. Uzmi ono dobro iz Angulara i Reacta, baci ostatak. Single File Components — template + script + style u jednom fajlu.

📦

Webpack + npm

Modules, bundling, tree-shaking. npm postaje de facto standard. node_modules postaje najteži folder na računaru.

⚛ React — jednosmerni tok podataka

ℹ️
Embedded React via CDN — ovo nije kompajlirani React sa npm i Webpack-om. React, ReactDOM i Babel su učitani direktno sa unpkg.com CDN-a. Babel transpajlira JSX u realnom vremenu u browseru. U produkciji — uvek koristiti build proces (Vite, Create React App). Ovde je samo radi demonstracije, bez ikakve instalacije.

Ukucaj ime u polje — sve tri komponente se ažuriraju iz jednog state-a. Otvori DevTools Console da vidiš re-rendere.

Pixel po piksel

Bootstrap i CSS3 su dali klijentima moć da vide savršen UI u browseru — i odmah im dali i milijardu ideja. Svaki dizajn je odjednom bio diskusija o tome da li je plava dovoljno plava.

"Pixel ovamo, piksel onamo... e ova plava treba da bude malo plavija... pravougaonik ima previše oštre uglove..."

"Ma to je za tebe lako"

Napredak u FE toolingu imao je neželjenu posledicu: klijenti su videli da se stvari brzo prave — i zaključili da je sve brzo.

"To su par linija koda, ne?"
"Može li da animira kad skrolujem?"
"Baš kao na onom sajtu, samo drugačije."
"Na mobilnom izgleda malo drugačije, to se lako fiksira?"
🤔
Zašto se ovo desilo baš u ovoj eri

Pre Bootstrap-a, klijent je dobijao statičan Photoshop mockup — i to je bio kraj diskusije. Kad je Bootstrap omogućio da se za sat napravi klikabilni prototype u browseru, svaki klijent je odjednom imao interaktivan referentni okvir za feedback. Što je dobro za produkt — ali je otvorilo Pandorinu kutiju sitnih izmena koje su individualno trivijalne, a skupno gutaju nedeljama.

Ovo je direktno rodilo industriju UX dizajnera, product owner-a i design systems-a — sve kao pokušaj da se taj haos strukturiše pre nego što kod uopšte počne.

How it feels to learn JavaScript in 2016

A satirical dialogue about modern JavaScript tooling overwhelm

— Hej, naučio sam JavaScript. Kako da napravim sajt?

— Super! Instaliraš Node, npm, zatim Webpack kao module bundler, Babel za transpilaciju ES6, React za UI, Redux za state, React-Router za routing, Axios za HTTP, Jest za testove, ESLint za linting...

— Čekaj, mislio sam samo da ispišem "Hello World" na ekran?

— Da, da. Ali najpre konfigurišeš webpack.config.js, .babelrc, .eslintrc, package.json scripts... Ah, i treba ti Yarn umesto npm-a, brži je. I probaj create-react-app, ali ne, to je za početnike. Bolje napravi svoju konfiguraciju da razumeš.

— Ali to je sve samo da pišem JavaScript?

— Pa, pišeš TypeScript, koji se kompajlira u JavaScript. I CSS-in-JS jer regular CSS je antipattern. I JSX koji izgleda kao HTML ali nije. I možda Flow za type checking mada TypeScript ionako...

— Idem nazad na jQuery.

Zašto je ovaj članak odjeknuo
2016. je bila godina u kojoj je JavaScript ekosistem eksplodirao u kompleksnosti. Na npm-u je objavljeno 150,000+ novih paketa te godine. Pojavili su se: Webpack 2, Angular 2 (rewrite!), Vue 2, Create React App, Yarn, Rollup, Parcel, CSS Modules, Styled Components, MobX... Članak je dobio 47,000+ reakcija jer je svaki developer prepoznao sebe.
