CSS Revolucija: Kraj Table Layouta

CSS je formalno postojao od 1996., ali do 2002–2003. brauzeri su ga implementirali prekratko i nekonzistentno. Sa dolaskom Firefoxa i popravljenim IE6, Web Standards Movement (Jeffrey Zeldman, Eric Meyer) napokon dobiva argumente: HTML za strukturu, CSS za izgled.

✗ Staro (tabele za layout)

  • Semantika unistena
  • Screen readeri necitljivi
  • 5–7 nivoa gnijezdjenja
  • Sporo renderiranje
  • Redesign = rewrite svega

✓ Novo (CSS float)

  • Semanticki HTML
  • Dostupnost poboljsana
  • Dizajn u CSS fajlu
  • Brzo renderiranje
  • Redesign = novi CSS

CSS Zen Garden (2003.) — Dokaz Koncepta

Dave Shea lansira csszengarden.com: jedan HTML fajl, 200+ potpuno razlicitih dizajna samo menjanjem CSS-a. Svaki skeptik koji je tvrdio “CSS ne moze to sto tabele mogu” ostaje bez argumenata.

Float Layout — Kako Je Izgledalo

Umjesto tabela, sada koristimo float: left za kolone. Zvuci jednostavno. Nije bilo. Clearfix je bio obavezan hack koji je sprecavao kolapiranje parent elementa.

/* 2-kolumni float layout — standard 2003-2010 */ #wrapper { width: 900px; margin: 0 auto; } #sidebar { float: left; width: 200px; } #main-content { float: left; width: 680px; } /* Clearfix — OBAVEZAN ili parent ima height: 0 */ #wrapper:after { content: "."; display: block; clear: both; visibility: hidden; height: 0; } #wrapper { zoom: 1; } /* IE6 fix */

⚠ IE6 Box Model Bug — Nocna Mora

  • W3C: width = samo sadrzaj, padding se dodaje
  • IE6: width = sadrzaj + padding + border (intuitivnije!)
  • Resenje: box-sizing: border-box (CSS3, 2010.)
  • Ironija: danas svi koriste IE6-ov model kao standard

Photoshop "Save for Web" — Rodjen Web Dizajner

Dok je CSS tek pokusavao da se izbori sa browserima, Adobe je 1999. u Photoshop 5.5 dodao "Save for Web", a 2000. u Photoshop 6.0 Slice tool. Odjednom — dizajner moze da napravi sajt bez ijedne linije HTML-a.

Dizajner napravi celu stranicu kao jednu sliku u Photoshopu. Isece je Slice tool-om na komadicima. Klikne "Save for Web" — Photoshop sam generise HTML fajl sa tabelom i folder pun GIF/JPEG slicica. Gotova veb stranica.


Bez ijedne linije rucno pisanog HTML-a.
Bez znanja o tabelama, colspan, rowspan.
Bez razumevanja sta je browser uopste.


Isti princip radio je i Macromedia Fireworks (1998.) i ImageReady koji je dosao uz Photoshop. Dreamweaver je takodje imao sopstveni slice alat.

Ajax — Stranica Bez Reload-a (2005.)

Jesse James Garrett imenuje tehniku 2005.: Asynchronous JavaScript and XML. Gmail (2004.) vec je dokazao koncept — email klijent u brauzeru, bez refresh-a. XMLHttpRequest je bio dio IE5 od 1999., ali niko ga nije koristio mainstream.

jQuery (2006.) — "Write Less, Do More"

John Resig objavljuje jQuery 1.0. Cilj: eliminisati bolnu brauzer-kompatibilnost. Isti kod radi u IE6, Firefoxu, Operi, Safariju. Onda je to bio gotovo cudo.

/* Bez jQuery — 2003. */ var el; if (document.getElementById) { el = document.getElementById('box'); } else if (document.all) { el = document.all['box']; // IE4 } else if (document.layers) { el = document.layers['box']; // Netscape 4 } el.style.display = 'none'; /* Sa jQuery — 2006. */ $('#box').hide();

Kafana Na Zici — Ispred Svog Vremena

Domen kafana-na-zici.com kupljen 2000. Vizija: digitalni ekvivalent kafane — stolovi, razgovori, mogucnost da oslusanes tudje. To je bila ideja Web 2.0 prije nego je Web 2.0 dobio ime.

Forumi koji su uslijedili (phpBB, vBulletin) implementirali su slicnu ideju tehnicki, ali su izgubili metaforu kafane — anonimni thread-ovi nisu isto sto i stolovi gdje znas ko sedi.
