Evolucija
CSS-a

CSS je počeo kao jednostavan jezik za boje i fontove. Za 30 godina postao je arhitekturalni problem koji je rodio preprocesore, metodologije, CSS-in-JS i na kraju — utiliti klase.

// hronologija — od CSS1 do danas
1994
Predlog
Håkon Wium Lie predlaže CSS
Dok radi sa Berners-Lijem u CERN-u, Håkon šalje predlog za "Cascading HTML style sheets". HTML 1.0 nema nikakvo stilizovanje — Berners-Li je namerno tako napravio. Lie je smatrao da je vizuelna prezentacija ipak važna.
1996
★ CSS 1
CSS Level 1 — W3C Recommendation
Font, boja, margine, padding, border. 92 propertija. Browseri ga podržavaju tek parcijalno. IE3 uvodi parcijalu podršku. Netscape se opire — ima sopstvene HTML atribute.
CSS 1 — 1996
body {
  font-family: Times New Roman;
  color: black;
  background: white;
}
h1 { font-size: 24pt; }
a { color: blue; }
92 propertija Font, boja, margine Browseri ne podržavaju sve
1998
CSS 2
CSS 2 — pozicioniranje, z-index, media types
position: absolute/relative/fixed, z-index, @media print. Ali IE implementacija je haotična — box model bug koji muči web do 2010. (IE računa padding unutar width, ostali van).
position: absolute z-index IE Box Model Bug
2006
★ Sass rođen
Sass — Hampton Catlin, Nathan Weizenbaum
Revolucija. Ruby on Rails projekat. Indented sintaksa (bez vitičastih zagrada). Varijable, nesting, mixini. CSS konačno dobija programske koncepte. 2009. dolazi SCSS — "Sassy CSS" sa vitičastim zagradama, kompatibilan sa postojećim CSS-om.
SCSS — 2009SCSS
// Varijable
$primary: #3498db;
$radius: 4px;

// Mixin
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

// Nesting
.btn {
  background: $primary;
  border-radius: $radius;
  &:hover {
    opacity: 0.8;
  }
}
$varijable Nesting @mixin @extend @import
2009
★ Less + CSS3
Less & CSS3 animacije — Bootstrap era počinje
Less (Alexis Sellier) — sličan Sass-u ali u JavaScriptu. Bootstrap 3 (2013) koristi Less — zato su ga svi koristili.

CSS3 — ne jedna spec nego moduli: border-radius, box-shadow, transition, animation, @keyframes, gradient. Kraj slike za svaki zaobljeni ugao.
Less varijable — Bootstrap stilLESS
// Less varijable sa @
@primary-color: #428bca;
@border-radius: 4px;
@font-size-base: 14px;

.btn-primary {
  background-color: @primary-color;
  border-radius: @border-radius;
  &:hover { opacity: .9; }
}
@varijable (Less) Bootstrap 3 = Less border-radius nativni transition, animation
2013
PostCSS & BEM
PostCSS — procesor, ne preprocesor
PostCSS nije preprocesor — procesor. Transformiše CSS kroz pluginove: Autoprefixer automatski dodaje -webkit-, -moz- prefikse. CSS Modules — scoped CSS u React projektima.

BEM metodologija (Block Element Modifier) — .block__element--modifier naming konvencija. Pokušaj da se organizuje CSS bez preprocesora.
Autoprefixer CSS Modules BEM konvencija
2015
★ CSS-in-JS era
CSS Modules + Styled Components — CSS ulazi u JS
React komponente dovode do pitanja: kako scopovati CSS? Globalni CSS je problem u SPA aplikacijama.

CSS Modules (2015) — klase postaju lokalne po defaultu, kompajler generiše unikalne nazive. Styled Components (2016) — CSS direktno u JavaScript stringu, uz punu JavaScript logiku.
Styled Components — 2016JS/CSS
import styled from 'styled-components';

const Button = styled.button`
  background: ${'${'}props => props.primary ? '#3498db' : 'white'${'}'};
  color: ${'${'}props => props.primary ? 'white' : '#333'${'}'};
  border-radius: 4px;
  padding: 8px 16px;
`;

// Upotreba:
<Button primary>Klikni</Button>
CSS Modules Styled Components Emotion Kontroverza traje
2017
★ CSS Custom Properties + Grid
Nativne CSS varijable — Sass više nije jedini
CSS Custom Properties — nativne varijable u browseru. Za razliku od Sass-a — mogu se menjati JavaScript-om u realnom vremenu, nasleđuju se kroz DOM, rade u media queryjima.

CSS Grid — Jen Simmons, Rachel Andrew. Kraj float hakova zauvek. Pravi 2D layout sistem.
CSS Custom Properties — 2017CSS
:root {
  --primary: #3498db;
  --radius: 4px;
}

.btn {
  background: var(--primary);
  border-radius: var(--radius);
}

/* JS može menjati u realnom vremenu: */
/* el.style.setProperty('--primary', '#e74c3c') */
--custom-properties CSS Grid JS može menjati Nasledjivanje kroz DOM
2017
★ Tailwind CSS
Tailwind — utility-first, kraj semantičnih klasa
Adam Wathan objavljuje Tailwind. Kontroverzno odmah. Umesto .btn-primary — pišeš direktno bg-blue-500 text-white rounded px-4 py-2 hover:opacity-90.

Kritika: HTML postaje nečitljiv. Odbrana: nema naming problema, nema nekorišćenog CSS-a, dizajn sistem ugrađen.
Tailwind vs klasični CSS
<!-- Klasični CSS -->
<button class="btn btn-primary">Klikni</button>

<!-- Tailwind -->
<button class="bg-blue-500 text-white
  rounded px-4 py-2 font-medium
  hover:bg-blue-600 transition">
  Klikni
</button>
Utility-first JIT compiler Design tokens Kontroverzno
2023+
Moderni CSS
CSS Nesting, :has(), container queries — CSS postaje moćan
CSS dobija nativni nesting (kao Sass), :has() selektor (parent selector koji su tražili 20 godina), container queries — komponenta reaguje na svog roditelja, ne na viewport. @layer — cascade layers za kontrolu specifičnosti.

Sass polako gubi razlog za postojanje — sve što je nudilo, CSS nativno implementira.
CSS Nesting nativni :has() selektor Container Queries @layer Sass — manje potreban
// preprocesor poređenje
Sass / SCSS

Sass — pionir

2006. Ruby, 2010. LibSass (C++), 2020. Dart Sass. $varijable, @mixin, @extend, & nesting, @function. Standard u dizajn sistemima. Bootstrap 4+ prešao na SCSS.

$varijable @mixin Bootstrap 4+
Less

Less — Bootstrap 3 era

2009. JavaScript, radi u browseru i na serveru. @varijable, mixini, nesting. Dominantan dok je Bootstrap 3 bio standard. Bootstrap 4 prešao na SCSS — Less gubi momentum.

@varijable Bootstrap 3 Manji momentum
Stylus

Stylus — maksimalna fleksibilnost

2010. Node.js, najpermisivnija sintaksa — možeš pisati sa ili bez vitičastih zagrada, sa ili bez dvotačke. Nikad nije uhvatio masu ali ima lojalne korisnike. Popularan u Vue.js ekosistemu.

Fleksibilna sintaksa Vue ekosistem Manja zajednica
// sass varijable vs css custom properties
Sass $varijable
$color: #3498db;

.btn {
  background: $color;
}

// Kompajlira se:
.btn {
  background: #3498db;
}

✗ Ne može se menjati JS-om
✗ Ne nasljeđuje se kroz DOM
✗ Ne radi u media queryjima
✓ Kompajlira se, nema runtime overhead

CSS Custom Properties
:root {
  --color: #3498db;
}

.btn {
  background: var(--color);
}

/* Mijenja se JS-om: */
/* el.style.setProperty(
  '--color', '#e74c3c') */

✓ Mijenja se JS-om u realnom vremenu
✓ Nasljeđuje se kroz DOM
✓ Radi u @media queryjima
✓ Dark mode trivijalan

💡
Zašto Sass i CSS Custom Properties koegzistiraju? Sass varijable su compile-time — idealne za design tokens koji se ne mijenjaju (spacing skala, breakpointi, font families). CSS Custom Properties su runtime — idealne za teme, dark mode, dinamičke boje koje JavaScript treba da mijenja. Moderni projekti koriste oboje.
// CSS metodologije — kako organizovati haos
BEM — 2009, Yandex

Block Element Modifier

Naming konvencija: .block__element--modifier. .card__title--featured. Cilj: predvidljivi CSS selektori, bez konflikata. Verbose ali eksplicitan. I danas popularan.

/* BEM */
.nav__item--active { color: blue; }
SMACSS, OOCSS, ITCSS

Arhitekturalne metodologije

SMACSS — kategorije: Base, Layout, Module, State, Theme. OOCSS — odvoji strukturu od vizuela. ITCSS — inverted triangle, od generičnog ka specifičnom. Sve pokušavaju da reše isti problem: CSS raste i postaje neodrivo.

CSS Modules — 2015

Lokalni scope po defaultu

U React/Webpack projektima. Pišeš .btn, kompajler generiše .btn_a7f3k — unikalan za svaku komponentu. Bez konflikata, bez globalnog zagađenja. Standard u React ekosistemu.

Tailwind — 2017

Utility-first — kraj metodologija?

Tailwind eliminiše potrebu za BEM, SMACSS i ostalima. Nema custom klasa — sve su utiliti klase. .flex .items-center .gap-4 .p-4. Design system je ugrađen u konfiguraciju. Kontroverzno ali dominantno.

🔄
Paradoks napretka u CSS-u: Sass je nastao jer CSS nije imao varijable — CSS ih je dobio 2017. Less je nastao jer nije bilo modularne organizacije — CSS Modules to rešavaju. Styled Components su nastali jer scoping nije postojao — Shadow DOM i CSS Modules to rešavaju.
